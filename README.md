# Undelete — сайт для GitHub Pages

Три страницы: `index.html` (главная), `offer/` (публичная оферта), `privacy/` (политика конфиденциальности).
Шрифты и картинки лежат внутри (`assets/`), внешних сервисов, cookies и аналитики нет.

## Что заполнить перед публикацией
Откройте `build.py`, блок `CFG` и текст оферты/политики. Всё, что осталось в [квадратных скобках], на странице
подсвечено жёлтым. Список выводится при запуске:

    python3 build.py

Скрипт пересоздаёт `index.html`, `offer/index.html`, `privacy/index.html`. После заполнения скобок жёлтой
подсветки на страницах не должно остаться.

## Публикация на GitHub Pages
1. Создайте репозиторий (например, `undelete-site`) и загрузите в его корень содержимое этой папки
   (включая файл `.nojekyll`, он нужен, чтобы GitHub не обрабатывал страницы Jekyll-ом).
2. Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
3. Адрес появится вида `https://<логин>.github.io/undelete-site/`. Страницы: `/offer/` и `/privacy/`.
4. Свой домен: в Settings → Pages → Custom domain укажите домен, у регистратора добавьте DNS-записи по подсказке
   GitHub, включите Enforce HTTPS.

## Дальше
- В Railway, в сервисе бота, задайте `OFFER_URL=https://ваш-адрес/offer/` — ссылка появится в `/start` и `/subscribe`.
- Тот же адрес главной страницы и страницы оферты указывайте в заявке на подключение платёжного сервиса.
- Если правите оферту в документе, не забудьте перенести правки в `build.py` (и наоборот).
